  Every snapshot contains TWO DISTINCT run ids — the `AgentRuntime`'s own
  (`run_DUXfjcLL`, `run_0JId2Tz6`, `run_F6IHdEyW`) and the
  `SessionRuntime`'s (`run_1793712207239_31xeui`, ...) — exactly as the

  have contained only the run-terminal record.

     sessionId      (identical within a snapshot, mandatory in the join)
     modelRequestId (identical within a snapshot)
  while BOTH distinct run ids are PRESERVED on their own records — they are
  never conflated, and the run result's own run id is not rewritten.
