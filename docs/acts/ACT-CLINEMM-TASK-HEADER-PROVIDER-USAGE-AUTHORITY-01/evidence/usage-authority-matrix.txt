ACT-CLINEMM-TASK-HEADER-PROVIDER-USAGE-AUTHORITY-01 — USAGE AUTHORITY MATRIX

Authority meanings
P = provider-reported input for the most recent eligible main-model usage event.
    Normalized buckets are disjoint: tokensIn + cacheReads + cacheWrites.
    Output tokens are excluded. No cross-request sum.
W = runtime-published prospective working-context estimate.
    Displayed only as an explicitly labeled next-request estimate; fallback when P is absent.
B = prospective compaction budget.
    UNCHANGED. No estimator, trigger, ceiling, summarizer, or compaction policy change.
