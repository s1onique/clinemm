10. PACKAGING DEFECT FIXED ALONG THE WAY (P2, pre-existing)
------------------------------------------------------------------------

`vsce package` aborted with:

    ERROR  Error occurred while scanning secrets (files): Error: EISDIR:
           illegal operation on a directory, read

The cause was the repo-root Bun install cache `.bun-install/`, which is
gitignored but was NOT excluded by `apps/vscode/.vscodeignore`, so it
was swept into the package. It contains an editor backup file
(`README.md~`) that the packaging secret scanner cannot read.

`apps/vscode/.vscodeignore` now excludes `**/.bun-install/**` and
`**/*~`. Nothing in that cache is needed at runtime (the bundled
`dist/extension.js` carries the code), and no `.bun-install` content is
in the packaged VSIX.

(The package was produced with `--no-dependencies`, which also skips the
dependency-tree secret scan; the `.vscodeignore` fix removes the root
cause for future packaging runs.)
