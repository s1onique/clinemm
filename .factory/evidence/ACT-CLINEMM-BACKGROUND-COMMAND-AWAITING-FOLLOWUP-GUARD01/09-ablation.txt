ABLATION — BCAFG01

Per ACT §11, ablation is required after candidate defect
identification. The discriminator test (BCAFG01) embeds the
ablation.

ABLATION FOR H2 (owner identity mismatch):

  Variable held constant:
    - activeSession.sessionId ("session-bcafg01")
    - job.state ("running")
    - presence of a RUNNING managed CommandJob in the active map
    - completion event (done-without-completion, same sessionId)

  Variable varied:
    - ownerSessionId stamp on the job (via context.sessionId at
      CommandJobManager.start() time)

  Result matrix:

    case    ownerSessionId stamp        lookup_result    writer_commits?
    ------  --------------------------  ---------------  ----------------
    A       activeSession.sessionId     true             NO (GREEN)
    B       undefined (no context)      false            YES (RED)
    C       a different sessionId       false            YES (RED — isolation control)

  Necessity: when stamped correctly (A), the writer is suppressed.
  Sufficiency: when stamped incorrectly (B/C), the writer commits.
  Both criteria met for H2.

ABLATION FOR H4 (guard result ignored) — embedded in
BCAFG01-ABLATION:

  Variable held constant:

    - ownerSessionId correctly stamped (case A precondition)

  Result:
    mockLiveness=true   → writer suppressed
    mockLiveness=false  → writer commits

  H4 (guard result ignored) is REFUTED.
