ACT-CLINEMM-EXTENSION-HOST-TERMINATION-AUTHORITY01 -- Conservation

The termination witness is DEFAULT_OFF (CLINEMM_DIAG_TERMINATION_AUTHORITY
unset or non-truthy keeps state=disabled). When disabled:

TATRM-CONSERVE-01  disabled-zero-semantic-delta
                   - installTerminationAuthorityWitness() returns
                     without installing ANY listeners on process.
                   - No writers, no readFileSync, no FS IO.
                   - __resetTerminationAuthorityForTests() can be
                     called at any time; safe to leave wired.
                   - State accessor always reports "disabled"; the
                     capturedId is undefined.

The DEFAULT_OFF state was verified by:

  - The vitest test suite TATRM-CONSERVE-01 counts listeners on
    process.before/after calling install(); asserts delta=0.
  - test:unit (bun:test runner) over 1168 tests in apps/vscode
    returned 0 failures -- the existing ACTs (CCARD, BTCONT, TQCB,
    ALLOCAUTH, CPUCAP, SLAC, EHLOOP, ...) are unaffected.

CORRECTION01 — Semantic-inertia discriminators (per operator directive):

  TATRM-CONSERVE-SIGNAL-01
                      The witness installs NO listener on
                      SIGHUP / SIGINT / SIGTERM. Verified by:
                      process.listenerCount("SIGTERM"|"SIGINT"|"SIGHUP")
                      is unchanged after installTerminationAuthorityWitness().
                      Installing any of these listeners would suppress
                      Node's default disposition (terminate on SIGINT/SIGTERM),
                      which is the exact authority we are trying to measure.

  TATRM-CONSERVE-REJECTION-01
                      The witness installs NO listener on
                      unhandledRejection / rejectionHandled.
                      Verified by listenerCount delta=0. Installing
                      unhandledRejection would suppress Node's default
                      `--unhandled-rejections=throw` behavior (which
                      raises an uncaught exception if no listener is
                      installed) and thereby change default fatal
                      behavior.

  TATRM-CONSERVE-SIGNAL-MUTATION-01
                      Stronger mutation check: a pre-existing SIGTERM
                      listener (added before install) survives the
                      witness install with no additional listener
                      registered. This proves the witness never
                      regresses to registering SIGTERM even under
                      mutation of the surrounding environment.

These three discriminators form the load-bearing boundary between
"observational only" (allowed) and "process-lifecycle altering"
(forbidden). The safe-list is FROZEN to exactly:

    beforeExit
    exit
    uncaughtExceptionMonitor
    warning

Any future ACT that wants to add a new channel MUST be a separate
correction ACT and MUST prove the new channel is observational for
process-termination attribution.
