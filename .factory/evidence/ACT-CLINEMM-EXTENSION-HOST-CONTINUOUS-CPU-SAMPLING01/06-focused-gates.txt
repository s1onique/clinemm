CORRECTION03 GATES (HALT_CPU_PROFILE_FINALIZATION_ROTATION_RACE):

    Per Leamas digest: state="rotating" does NOT mean "Profiler is
    running". After correction02, rotate() set state="rotating" and
    stopped profiling BEFORE checking MAX_DURATION. The old finalizer
    used `if (_state === "active" || _state === "rotating")` and
    therefore issued a phantom Profiler.stop on the rotation-driven
    horizon path. Corrected with explicit `profilerRunning` boolean
    that is set/cleared at every Profiler.start/Profiler.stop boundary.

CORRECTION04 GATES (HALT_CPU_PROFILE_STOP_INFLIGHT_FINALIZER_RACE):

    Per Leamas digest: correction03 gated Profiler.stop on
    `profilerRunning`, but `profilerRunning` stays true for the
    ENTIRE await session.post("Profiler.stop") window. A
    concurrent finalizer firing in that window sees
    profilerRunning=true and posts a duplicate stop.

    The corrected invariant is "at most one Profiler.stop may be
    outstanding at any moment". Enforced by:
      - stopInFlight boolean set synchronously BEFORE every
        await session.post("Profiler.stop") and cleared AFTER.
      - inFlightStopPromise shared between rotate() and
        finalizeActiveCapture() — concurrent finalizer awaits
        the existing Promise instead of issuing a duplicate.
      - rotationSettled Promise resolved only when rotate() body
        fully settles — concurrent finalizer awaits it before
        cleanup+meta so meta writes observe rotation's counter
        updates.
      - disconnected boolean set in cleanup() — rotate()'s
        post-rotation Profiler.start guarded by
        `if (disconnected) return false` so it does not crash on
        a disconnected session when finalizer ran concurrently.

    [X] CPUCAP-FINAL-INFLIGHT-STOP-01: finalizer fires while
        rotate()'s Profiler.stop is in flight -> no duplicate
        Profiler.stop; one authoritative completed segment;
        state=finalized.

    Fault-injection verification:
      - Replaced `if (profilerRunning && !concurrentStopInFlight)`
        with `if (true)` (ignore in-flight gate).
      - Result: CPUCAP-FINAL-INFLIGHT-STOP-01 FAILS as expected
        with `AssertionError: expected 2 to be 1` (phantom 2nd
        Profiler.stop from finalizer).
      - Reverted. All 31/31 PASS again.
