## Smoke probe validation (real Node, per ACT §24)

scripts/inspector-cpu-smoke-probe.mjs was executed against the real
Node Inspector backend. The probe:

    1. Connected via node:inspector Session
    2. Called Profiler.enable
    3. Called Profiler.setSamplingInterval { interval: 1000 }    # explicit, not default
    4. Called Profiler.start
    5. Ran a 1-second bounded CPU workload (Math.sqrt + Math.sin)
    6. Called Profiler.stop
    7. Asserted: profile.nodes.length > 0
                profile.samples.length > 0
                profile.timeDeltas.length > 0

Result: PASS
    Profiler.enable ok
    Profiler.setSamplingInterval ok (interval=1000us)
    Profiler.start ok
    Profiler.stop returned profile: nodes=5 samples=793 timeDeltas=793
    smoke probe PASS

This proves:
    - Node accepts Profiler.setSamplingInterval with interval=1000us
    - Node returns a complete Profile object via Profiler.stop
    - The profile is structured as { nodes, samples, timeDeltas, startTime, endTime }
    - The "profile" envelope is NOT wrapped in this Node version (top-level fields)
