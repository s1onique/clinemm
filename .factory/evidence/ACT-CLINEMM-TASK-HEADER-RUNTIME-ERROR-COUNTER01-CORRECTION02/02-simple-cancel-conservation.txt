# Why this is the right witness
# The test sleep is a single-process tree (sh → sleep), owned by the
# ClineMM supervisor, and SIGTERM-able by the supervisor's PGID. On
# macOS, kill() against a negative PID is denied only when the
# signaling process lacks entitlement to signal one or more group
# members. The ClineMM supervisor's parent (VSCodium helper) is NOT
# sandbox-restricted from signaling its OWN group, so a clean
# sh+sleep group responds to SIGTERM normally.
#
# This is the LIVE analogue of REC-BE-08 (ordinary exit does NOT
# increment) and pins the conservation claim directly on the real
