      typical bash-executor timeout"
     Expected: process.kill(pid, 0) succeeds (child still alive)
     Actual:   process.kill(pid, 0) returns EPERM
     Causal:   the spawned Node child cannot be probed because the VSCodium
               Helper (Plugin) sandbox blocks kill() syscall.
  2) "terminateTree (CORRECTION03: process-tree supervision) >
      gracefully terminates a cooperative tree (no SIGKILL needed)"
     Expected: result.treeTerminated === true after 2s grace
     Actual:   result.treeTerminated === false
     Causal:   SIGTERM to -pgid returns EPERM (VSCodium sandbox).
               probePgidExists() interprets EPERM as "still exists"
               (bash.ts:1018), so the grace window expires with
               "still exists" assertion, then SIGKILL also EPERMs,
               then probePgidExists() still returns true → treeTerminated=false.

               attempted; outcome reported wrong because EPERM blocks probe).
  4) "terminateTree (CORRECTION03: process-tree supervision) >

     Same root cause; both terminateTree calls cannot probe outcome.

  CLASS: H = REAP/COMPLETION BUG (probePgidExists EPERM semantics)
  FIRST_BAD_BOUNDARY: probePgidExists treats EPERM as "group still exists"
                      (bash.ts:1018), which is correct in pure POSIX semantics

Distinction:
  - Cline Seatbelt profile (sdk/packages/core/.../seatbelt-profile.ts:10):
    `(allow signal (target self))` — operates on the SANDBOXED CHILD'S outbound
    signal syscalls. It does NOT block incoming signals from the host Node parent.
    Signal delivery to the sandboxed child is kernel-routed normally.
  - VSCodium Chromium sandbox (Helper --enable-sandbox): operates on the HOST
    Node parent's outbound signal syscalls. THIS is what blocks process.kill()
    with EPERM in this authoring environment.

The CORRECTION03 P0 production repair in bash.ts is CORRECT for non-sandboxed
parent contexts (real CLI / real native spawn outside Chromium zygote). The
test failures are an ENVIRONMENT artifact, not a code defect.
