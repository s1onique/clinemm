The bootstrap refused (CURRENT_CONFIGURATION_UNSUPPORTED) because
the user's legacy persisted openAiHeaders was `{}`. The runtime
authority `...(openAiHeaders || {})` treats empty and absent as
identical, so this refusal is a bootstrap/runtime semantic mismatch,
not a legitimate user-config issue.
