IMPLEMENTATION CONTRACT
================================================================================

(1) TYPE SPLIT (compile-time defense):

  leaves:
    FactoryBindingProbeCapability = { kind: "factory-binding-probe", correlationId: string }
    FilesystemCreateOnlyCapability = { kind: "filesystem-create-only", roots: ReadonlyArray<string> }

  legacy tool-call channel (factory-binding-probe ONLY):
    ToolCallExecutionCapability = FactoryBindingProbeCapability

  full union (used by per-command channel):
    InternalExecutionCapability = FactoryBindingProbeCapability | FilesystemCreateOnlyCapability

  field assignments:
    ToolApprovalResult.executionCapability:     ToolCallExecutionCapability
    AgentToolContext.executionCapability:      ToolCallExecutionCapability
    PreparedToolExecution.executionCapability: ToolCallExecutionCapability
    CommandExecutionPlanEntry.executionCapability: InternalExecutionCapability

(2) RUNTIME GUARD (actual security boundary):

  In executeShellCommands, BEFORE Promise.all:
    if (perCommandCaps === null && context.executionCapability !== undefined) {
      if (context.executionCapability.kind !== "factory-binding-probe") {
        throw new Error("real_execution_capability_requires_per_command_plan: ...");
      }
    }

  This enforces: the legacy tool-call channel may carry ONLY the synthetic
  probe (or nothing). Any other kind requires a per-command execution plan.

  The runtime guard is the actual security boundary; TypeScript narrows
  the type system but the runtime defends against JSON deserialization,
  future code paths that bypass the type check, or any cast that slips
  through review.

(3) CAST AT EXECUTOR BOUNDARY:

  When perCommandCaps !== null, the per-command context widens back to the
  full union via an explicit cast at the executor boundary:
    perCommandContext = { ...context, executionCapability: perCommandCaps[i] } as AgentToolContext

  This is the ONLY place the cast exists. The boundary is documented in the
  production code. The runtime guard at the top of the function has already
  enforced the no-plan branch; here, when a plan IS present, the per-command
  slot IS the authority-bearing channel (which is by design).
