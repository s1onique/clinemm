REVIEWER HALT (from the Factory reviewer on CORRECTION03)
  New P0 -- HALT_RUNTIME_PATH_SHAPE_BYPASS:

  The write validator correctly rejects relative paths and the
  filesystem root "/" but the runtime defense-in-depth filter
  (`filterActiveTemporaryExternalPathEntries`) does NOT re-check
  `isAbsolute(path)` or `path !== "/"`. Therefore tampered
  persisted state such as
  `{ "path": "/", "expiresAt": "<now + 1h>" }` would survive the
  filter, get realpath-canonicalized to "/" (trivially widening
  R0 authority to every canonical path), and bypass the bounded
  "narrow escape hatch" contract.

  Likewise tampered `"../tmp"` would acquire CWD-relative meaning
  during `realpathSync`, recreating the CWD-dependent authority
  identity CORRECTION02 explicitly closed.

  P1 -- UI_STATE_STALE_CROSS_INSTANCE: cross-instance Settings
  UI can still display stale authorities (NON-BLOCKING).

PURPOSE OF THIS CORRECTION
  Bounded single-axis correction. Apply the same structural
  path-shape constraints (`isAbsolute(path)`, `path !== "/"`) at
  the runtime consumption filter as the write validator already
  applies, via a small shared predicate
  `classifyTemporaryExternalPathShape(path)`. Two enforcement
  points, one source-of-truth. CORRECTION03 architecture is
  preserved unchanged.

RED → GREEN TRACE
  Pre-CORRECTION04 (the bug):
    filterActiveTemporaryExternalPathEntries accepts `"/"`,
    `"tmp"`, `"../tmp"`, `"."` paths that have valid expiry.
    The downstream realpath-canonicalization step in
    `resolveActiveTemporaryExternalCanonicalRootsFromBackingFile`
    then forwards canonical variants as effective temporary
    roots.
    realpath("/") = "/"; workspaceRoots ∪ ["/"] trivially
    contains every canonical path (R0 gateway silently disabled).
    realpath("../tmp") = CWD-relative (CWD-dependent authority
    identity reintroduced, violating CORRECTION02 invariant).

  Post-CORRECTION04 (this fix):
    filterActiveTemporaryExternalPathEntries applies
    `classifyTemporaryExternalPathShape(entry.path) !== "valid"`
    and continues on every non-valid shape. Tampered entries
    never reach realpath-canonicalization. Adversarial tests
    in §4 of the ACT body are all PASS.
