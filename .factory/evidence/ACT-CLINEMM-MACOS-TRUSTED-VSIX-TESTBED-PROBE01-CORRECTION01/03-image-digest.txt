ACT-CLINEMM-MACOS-TRUSTED-VSIX-TESTBED-PROBE01-CORRECTION01 — image digest

P0-2 fix evidence: the Cirrus Labs Sonoma base image registry has
exactly one published tag.

Anonymous registry query:
  $ curl -s https://ghcr.io/token?scope=repository:cirruslabs/macos-sonoma-base:pull&service=ghcr.io
  {
    "token": "<public-anonymous-bearer: djE6<base64 of v1:cirruslabs/macos-sonoma-base:1789228734550985567>>"
  }

  $ curl -s \
      -H "Authorization: Bearer <public-anonymous-bearer>" \
      https://ghcr.io/v2/cirruslabs/macos-sonoma-base/tags/list \
      | python3 -c 'import json,sys; d=json.load(sys.stdin); print("count:",len(d.get("tags",[]))); print(d.get("tags",[]))'
  count: 1
  ['latest']

The only tag is `latest`. There is NO `:14.5`, NO `:15.0`, NO `:sonoma`.
Cirrus Labs publishes this base as a mutable `:latest`; reproducibility
comes from binding the immutable digest.

GitHub packages UI confirms the digest:
  Package macos-sonoma-base · Public
  Latest: ghcr.io/cirruslabs/macos-sonoma-base:latest
  Recent tagged image versions:
    latest
      Published 7 days ago
      Digest: sha256:e2ebdfc4d354b336fe00d729c11a8136a019b8046f41cc183a2fe51b85d18f49

Source binding (tools/macos-vsix-testbed/runner.ts):
  export const TART_BASE_IMAGE =
    process.env.CLINEMM_TART_BASE_IMAGE ??
    "ghcr.io/cirruslabs/macos-sonoma-base@sha256:e2ebdfc4d354b336fe00d729c11a8136a019b8046f41cc183a2fe51b85d18f49"

This reference is immutable; if `latest` is re-published the digest
changes and our build breaks loudly instead of silently pulling a
new base image. That is the correct invariant for a "pinned" image.

Override via CLINEMM_TART_BASE_IMAGE is preserved for development.
The pinned default is what the ACT §5 evidence binds.
