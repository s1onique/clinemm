================================================================================
02-launchd-green-c-fallback.txt — C binary self-bind round-trip (GREEN)
================================================================================

OBJECTIVE
---------
Prove that the compiled C helper:
  1. Binds the AF_UNIX socket when launched outside launchd
     (i.e., the fallback path is honest and works end-to-end).
  2. Sets mode 0600.
  3. Accepts connections and replies with the protocol envelope.
  4. Rejects exec-shaped payloads with FORBIDDEN_KEY.
  5. Reports its activation status via the status file mechanism.

This is the FALLBACK GREEN. The activation GREEN (under real launchd)
is substrate-deferred and recorded in 03-launchd-green-c-activation.txt.
