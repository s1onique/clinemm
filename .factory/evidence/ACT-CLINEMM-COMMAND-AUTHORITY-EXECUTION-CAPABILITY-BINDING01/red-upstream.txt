  DO add a typed runtime-owned field on AgentToolContext:
    executionCapability?: InternalExecutionCapability
  The host's authorization callback returns a typed object the
  runtime stamps into THIS slot, not into generic metadata.
  The runtime's agent-runtime.ts:2780 site changes from:
    metadata: this.config.toolContextMetadata
  to:
    {
      ...this.config.toolContextMetadata,
      executionCapability: ??? <-- typed slot from approval result

  (or similar; the key idea is that the new field is a TYPED SLOT
  the runtime owns, NOT a generic metadata key.)

  Model/stream metadata CANNOT populate this slot because the
  runtime owns the writer. Generic metadata continues to carry
  generic runtime context (unchanged).
