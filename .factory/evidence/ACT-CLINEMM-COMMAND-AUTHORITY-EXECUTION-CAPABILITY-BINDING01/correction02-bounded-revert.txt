ROOT CAUSE OF THE BOUND:
  In the prior C2-P1 commit, `bunx biome check --write --unsafe`
  was run across the four SDK-package files. Biome's
  autofixer changed three of them in ways that are semantically
  inconsequential (collapsing a single-variant union to its bare
  shape) or formatting (import-sort + indent re-flow), and one
  in a way that is semantically consequential (void ->
  undefined on a public interface field). The autofix ran
  WITHOUT diffing the changes against the C2 GREEN state, so
  the scope of the commit was misreported.

CORRECTION:
  The autofix must never run across production files without
  a human reviewer. Going forward: `biome check --diagnostic-
  level=error` ONLY (no --write --unsafe) on production files;
  format/import-sort fixes go in a separate dedicated commit
  that is itself diff-reviewed.
