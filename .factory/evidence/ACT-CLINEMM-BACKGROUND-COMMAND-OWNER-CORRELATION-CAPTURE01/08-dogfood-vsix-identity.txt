OPERATOR PROCEDURE (per ACT sec 26)
===================================

After the operator installs this ACT's diagnostic build into
their dogfood ClineMM instance:

  1. Install the fresh dogfood VSIX:
     code --install-extension <path-to-clinemm-vsix>
  2. Verify installed version when practical:
     code --list-extensions --product=clinemm
  3. Reproduce: send the agent a task that runs a managed
     background command such as:
       sh -c 'echo STARTED; sleep 600; echo FINISHED'
  4. Wait for the failure (Working -> Your turn with a
     Backgrounded / Cancel / jobId still visible).
  5. Cmd+Shift+P -> Cline Debug: Dump Background Owner
     Correlation.
  6. Record the notification path.
  7. Cmd+Shift+P -> Cline: Dump Turn State Writer Provenance
     Diagnostic.
  8. Record that notification path too.
  9. Preserve both .jsonl files.
  10. Preserve the screenshot showing jobId / Backgrounded /
      Cancel / Your turn.

The BOCOR .jsonl at step 9 is the LIVE evidence; the
classification per ACT sec 27 is then mechanical.
