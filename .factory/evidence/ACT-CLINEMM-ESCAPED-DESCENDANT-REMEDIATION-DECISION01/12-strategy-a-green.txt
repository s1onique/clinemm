CORRECTION01 narrowing (per `HALT_DECISION_EVIDENCE_OVERCLAIM_AND_NOT_DURABLE`):
  The original wording said "Strategy A is REJECTED FOR THIS SUBSTRATE
  rather than 'not proven'". The honest claim is narrower:

  - In THIS execution context (a sandboxed ClineMM agent process),
    sandbox_apply returns EPERM for every profile we can write,
    including the trivial `(allow default)`. This blocks the
    discriminating experiment in this context.

  - It does NOT prove that Strategy A is globally infeasible on
    Sonoma. Apple documents that child processes inherit a parent's
    static sandbox, so the EPERM observed from a sandboxed parent
    is not evidence that Seatbelt is unavailable on the host. Global
    viability requires un-sandboxed developer-Mac qualification
    (precedent: ACT-CLINEMM-SEATBELT-GO-DEFAULT-CACHE01).

  - The blanket `(deny process-fork)` profile shown above is also
    not the target primitive; the actual containment goal would be
    a finer-grained SBPL policy that allows ordinary fork/exec and
    only blocks session establishment. The 4-path inventory proves
    that this blanket shape is NOT viable; it does NOT prove that
    no finer-grained shape is viable.

Therefore, in this ACT:

  STRATEGY_A_CURRENTLY_QUALIFIED          = NO
  STRATEGY_A_GLOBALLY_INFEASIBLE_ON_SONOMA = NOT_PROVEN (claim not made)
