HALT_HOST_SUBSTRATE_UNAVAILABLE

The §4 three-point host ablation cannot be driven from this shell
because the bash process is itself running inside a Chromium sandbox
spawned by VSCodium's `--enable-sandbox` utility helper. That sandbox
strips the entitlement required by `/usr/bin/sandbox-exec` to apply a
new sandbox envelope. Every Seatbelt probe at this shell returns
`sandbox-exec: sandbox_apply: Operation not permitted` BEFORE the
profile is evaluated — so the probe cannot discriminate Seatbelt's
network-rule behavior from the parent-sandbox denial.

This is a substrate-availability failure, not a defect in the ClineMM
Seatbelt substrate and not a defect in the test infrastructure. The
`HAS_SUBSTRATE` gate in the c3-real-kernel suite is exactly the
mechanism designed to detect this state, and the gate fires correctly.
