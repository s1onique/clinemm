The C helper provides the load-bearing scp primitives
(tbr_scp_invoke, tbr_scp_in, tbr_scp_out) plus tbr_ssh_exec which
can run any command on the guest and capture stdout/stderr/exit.
These are sufficient to:
  - scp the host-side result to /tmp/clinemm-dogfood01-result (in)
  - ssh-run a guest command that writes a result file (out)
  - scp the guest result back to host (out)
  - sha256 both copies via tbr_sha256_file

The synthetic lifecycle in this ACT uses `tbr_ssh_exec` to run the
caller's commands[].argv on the guest (informational). A full
real-guest-result transfer (host<->guest artifact round-trip) is a
follow-up: it needs the real Tart + OCI image + a reachable SSH
endpoint, gated by C10/C11. The primitives are wired and ready.
