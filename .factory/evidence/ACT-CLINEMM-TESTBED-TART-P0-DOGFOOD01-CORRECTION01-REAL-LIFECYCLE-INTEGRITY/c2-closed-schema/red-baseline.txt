DEFECT: hasForbiddenKeysDeep in tools/macos-host-helper/protocol.ts
(line 605) allows `argv` ANYWHERE its value is an array of strings.
This means a malicious caller can place { argv: ["..."] } inside any
spec sub-object (metadata, timeouts, artifacts[*], etc.) and bypass
the closed-schema guard. The fix tightens the exception so argv is
ONLY allowed when the key's parent chain is exactly
[spec_root, "commands", i].

The C helper does NOT parse spec internally; spec travels as a
JSON-encoded string per LAUNCHD-RUNNER01. The TS parse layer is the
load-bearing authority on closed-schema. The C helper's job is to
re-enforce the closed-schema shape on the spec string via a focused
re-parse in handle_tart_testbed_run (defense in depth).
