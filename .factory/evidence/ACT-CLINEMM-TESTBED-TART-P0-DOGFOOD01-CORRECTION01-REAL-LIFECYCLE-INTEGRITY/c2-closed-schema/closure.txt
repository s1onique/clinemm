C2 CLOSED — closed-schema argv exception tightened to commands[*] only

Date: 2026-10-08
Subject HEAD: d46223b51 (start of ACT)

DEFECT (verified RED, then fixed):
  protocol.ts hasForbiddenKeysDeep(v, parentChain=[]) previously
  accepted `argv` ANYWHERE its value was an array-of-strings. The
  argv-exception was based on value-shape, not on parent-chain, so
  a malicious caller could embed `{argv: ["echo", "leak"]}` inside
  spec.metadata, spec.timeouts, spec.artifacts[*], or spec root,
  and the parser would accept it. This bypassed the closed-schema
  invariant for the spec.

FIX:
  hasForbiddenKeysDeep now threads a parentChain parameter through
  recursion. The argv exception is granted ONLY when the immediate
  parent key is `commands` (i.e. the array element is a direct child
  of spec.commands). argv anywhere else — root, metadata[*],
  artifacts[*], timeouts.*, etc. — is rejected as exec-shaped.
