C6 KEEP_VM — checked BEFORE stop/delete

Date: 2026-10-08
Subject HEAD: d46223b51

In handle_tart_testbed_run, the lifecycle checks `s.keep_vm`
BEFORE invoking stop/delete:

  if (s.keep_vm) {
    tbr_emit_result_ok(... overallStatus="KEEP_VM" ...);
    return;
  }
  // DELETE only if keep_vm is false

This is the order required by the brief ("keep_vm is evaluated
AFTER stop/delete have already happened" is the defect being
closed; the fix is to evaluate BEFORE teardown).

Synthetic test (TBRUNNER-C-09-2) verifies that even when keep_vm=true,
the lifecycle still emits the primary failure (TART_SSH_TIMEOUT)
when SSH fails — primary failure > keep_vm status. Real Tart with
a successful lifecycle would emit overallStatus="KEEP_VM" without
the DELETE step.
