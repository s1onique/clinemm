### apps/vscode/src/sdk/background-notify-coordinator.ts (NEW)
  - Process-ephemeral coordinator.
  - notificationMarkers: Map<jobId, NotificationMarker>.
  - heldTerminalResults: Map<ownerKey, TerminalNotification[]>.
  - registerMarker({jobId, sessionId, taskId}) — idempotent on
    jobId. No epoch field.
  - consumeTerminal({jobId, terminalState, exitCode, reason,
    isContainmentFailed, outputTail}) — single consumer; no
    second path; marker removed exactly once.
  - HOLD-vs-DRAIN FIFO by createdAtMs.
  - containment_failed -> containment_no_wake (N9).
  - owner_absent or owner_mismatch -> discarded (N4).
  - EPHEMERAL_ONLY enforced via dispose() (no DB write, no
    disk persistence).
  - formatTerminalWakePrompt produces a UTF-8-bounded string
    with hard cap NOTIFY_WAKE_PROMPT_MAX_BYTES (8 KiB).
  - truncateToByteCap is code-point-boundary safe
    (Buffer.byteLength, not character count).
