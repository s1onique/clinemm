Detection of containment_failed (correction01 N9 invariant):
  authoritative via snapshot.state === "containment_failed"
  (the bounded discriminator exposed via manager.status().snapshot).
  The wake consumer treats the state as the authority and forwards
  it as the `isContainmentFailed` flag to the coordinator.

Fast-path / synchronous terminality (correction01 P1-1 fix):
  When the manager's makeStartResult returns state="exited" at the
  tool's outer await (the wait budget didn't expire; the subprocess
  finished in milliseconds), the model already receives the
  synchronous terminal result via combinedOutput / CommandExitError.
  Registering a marker + wake in that path would produce a
  DUPLICATE follow-up turn (synchronous tool result + later
  notification). correction01 binds marker registration to
  `start.state === "running"` (genuine background handoff) so
  fast-path / synchronous terminality produces ZERO wake.
  Witness: BCNT-FAST-01.

FIFO drain (multi-job):
  J1 + J2 both notify=true.
  J1 terminal  ->  remainingNotify = 1 -> HOLD J1
  J2 terminal  ->  remainingNotify = 0 -> DRAIN J1 FIFO first,
                                       then J2 (exactly 2 wakes total).
  Witness: BCNT-06.
