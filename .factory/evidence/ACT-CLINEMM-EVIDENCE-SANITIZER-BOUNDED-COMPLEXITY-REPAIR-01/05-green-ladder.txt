BOUNDED COMPLEXITY ARGUMENT (STRUCTURAL, not a timing argument)
  operation 1: the guard (?<![A-Za-z0-9_.-]) makes a match ATTEMPTABLE only at the
    start of a key run. The number of attemptable positions is O(number of key
    runs), NOT O(body length). No offset inside a run is attemptable, so the
    quadratic "retry at every offset" behaviour is structurally impossible.
  operation 3: the END markers are located in ONE left-to-right pass; the BEGIN
    scan advances a monotone cursor and each pairing is a BINARY SEARCH over the
    already-located END markers. There is no forward rescan of the body from any
    BEGIN marker, so "markers x body length" is structurally impossible.
