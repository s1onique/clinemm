16) Round-6 P0: ssh_host_public_key provenance was unauthenticated
=========================================================================

Reviewer's P0 (round 6):

  > The proposed reopen condition says the trusted value is
  > captured with:
  >   ssh-keyscan -t ed25519 $guest_ip
  > and then persisted as ssh_host_public_key.
  > That does NOT establish trust in the key. OpenSSH's own
  > ssh-keyscan manual explicitly warns that constructing
  > known_hosts from unverified ssh-keyscan output leaves
  > users vulnerable to MITM. ssh-keyscan merely asks whatever
  > server answers at that address for its public host key;
  > it does not authenticate that answer.
  >
  > HALT_SSH_HOST_KEY_PIN_NOT_AUTHENTICATED_AT_QUALIFICATION.

The reviewer's discriminator:

  One discriminator is enough: show that the ssh_host_public_key
  written to config.json comes from the guest's actual host-key
  material, not from unauthenticated ssh-keyscan output.
  ssh-keyscan may still be used afterward as a comparison
  probe, but not as the root of trust.

Bounded fix:

M: tools/macos-vsix-testbed/testbed-image.ts
  + New helper captureGuestSshHostPublicKey() reads
    /etc/ssh/ssh_host_ed25519_key.pub from INSIDE the
    qualified VM through the already-authenticated
    provisioning channel (sshpass + admin/admin). The
    captured key IS the key sshd will present on every clone
    of this OCI image, because sshd reads the host keys from
    /etc/ssh/ssh_host_*_key.pub on every boot. So capturing
    the file content via the authenticated admin channel
    during qualification produces a pin that is
    cryptographically bound to the same key sshd will
    present at runtime — with NO man-in-the-middle window
    between the observation and the trust establishment.
  + Helper takes an optional runCommand seam so unit tests
    can exercise every failure mode without an actual SSH
    server.
  + Helper validates the captured line: rejects embedded
    newlines (would smuggle additional known_hosts markers),
    rejects leading @ (revoked/CA marker), | (hashed host),
    # (comment); requires one of the 5 allowed key types
    (ssh-ed25519, ecdsa-sha2-nistp256, ssh-rsa, rsa-sha2-256,
    rsa-sha2-512); requires base64 body of >= 43 chars;
    rejects > 3 whitespace-separated tokens (would smuggle
    a host field).
  + runQualifier() now calls captureGuestSshHostPublicKey()
    and emits ssh_host_public_key + ssh_host_public_key_path
    in the qualifier envelope. CLINEMM_TESTBED_IMAGE_GUEST_IP
    env var gates the capture; if unset, fails closed with
    SSH_HOST_KEY_NOT_FOUND.
  + Qualifier envelope Result type now has 2 new required
