    REACHABILITY ✓
      - existing durable artifact for the authoritative
        compaction seam (architecture doc §9 line 487:
        "persist the latest compacted working context
        as a session compaction artifact")
      - already crosses agents->core->host->VSCode
      - already accepts scalar metadata
      - canonical place where the producer seam's
        messages + system_prompt are stored
    CADENCE  ✗  (eighth-pass halt
                  HALT_WRONG_CARRIER_SEMANTICS)
      - createCompactionStateAwarePrepareTurn calls
        input.saveState ONLY inside the
        `if (result?.messages)` branches
        (compaction.ts:705, :720)
      - on an ordinary prepare-turn where the upstream
        `compact` returned undefined (no compaction
        needed), saveState is NEVER called
      - AND publishWorkingContextEstimate is NOT
        called on the no-compaction branch either
        (compaction.ts:730 returns `result` which is
        undefined)
      - so W is not published AND not persisted on
        ordinary turns
      - the carrier moves ONLY when compaction
        rewrites messages; that is the wrong cadence
        for C2 (which requires live current W on
        every authoritative prepare-turn)

  PROVISIONAL USE OF SessionCompactionState:
    valuable for resume qualification
    (durable W at compacted boundary + canonical
    tail projection); NOT the C2 live carrier.

  REJECTED candidate: AgentModelRequest
    - would require widening the request shape
      beyond provider-usage semantics
    - crosses only @cline/agents -> @cline/llms
      (request flow), not @cline/agents ->
      @cline/core (stateful orchestration)
    - architecture doc §9 line 489: "keep
      compaction logic out of the low-level
      agent message builder"
    - request carries provider-bound state; W is
      compaction telemetry, not a request field

  REJECTED candidate: runtime-event metadata
    - core only emits typed event metadata; no
      generic opaque scalar payload
    - widening this surface would create a NEW
      protocol field (more invasive than the
      chosen bound)

  The audit picks the LOWEST already-authoritative
  existing seam. No new protocol field, no
  AgentModelRequest mutation, no ChatView recompute.
