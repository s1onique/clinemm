  8. (void)stop_inv replaced with explicit TART_STOP_FAILED gate.

Test seam rationale (per ACT §1 "no new helper, no general-purpose
host execution API"):
  - CLINEMM_HELPER_TOOL_DIR is only honored at runtime; the
    production plist does NOT set it, so production code path is
    unchanged.
  - FAKE_SSH_* passthru only fires when the value is /tmp/-rooted;
    the production plist does NOT set these vars. Defense in
    depth: even if a future bug sets the var, it cannot point
    outside /tmp/.
