  i.e. perfectly valid TaskMsgs with a non-"noop" event

  untouched. The label-based proxy could not distinguish
  those from real mutations; they advanced the stamp and
  restored the LIVE contradiction.

PURPOSE OF THIS CORRECTION
  Bounded single-axis correction. Replace the
  `event !== "noop"` label proxy with the canonical
  structural-equality check `isSameTaskModel`
  (@cline/agents/runtime/state/task-state/model.ts). The
  stamp now advances only when the shadow model
  structurally changed between pre- and post- observation,
  OR when this is the comparator's very first observation
  (no pre-model to compare against).

  The boundary methods (observeRuntimeEvent, observeTaskMsg)
  snapshot the shadow model BEFORE replay, then pass the
  pre-model into compareWith. compareWith additionally
  retains the `event !== "noop"` belt-and-braces guard so
  the adapter sentinel path remains forbidden.
