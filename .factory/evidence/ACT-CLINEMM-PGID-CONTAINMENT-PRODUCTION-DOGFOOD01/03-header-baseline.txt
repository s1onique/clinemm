Step 03 — Baseline visible telemetry.

ENTRY_ACTIVE_COMMAND_JOBS = 0

Method: ClineMM state is owned by the extension host. Production telemetry surface is the
webview header (⎇ = active jobs count, ⚠ = runtime incident count). The only programmatic
production seam to inspect this state is the debug harness's `web.evaluate` (gauge text
extraction) or `ext.evaluate` against the Task class instance.

Both of those seams require the debug harness (apps/vscode/src/dev/debug-harness/server.ts)
on port 19229 connected to the running .vscodium-clinemm VSCodium instance. As of ENTRY:
  $ lsof -i :19229 → empty
  $ pgrep -fl debug-harness → empty
  $ curl http://localhost:19229/api → connection refused

The debug harness was FORBIDDEN to launch by user directive during this ACT
("Don't run the debug harness"). Without it, the production telemetry surface cannot
be programmatically observed — only a human viewing the ClineMM webview header can
verify ⎇ N → ⎇ N+1 in real time.
