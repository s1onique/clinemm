### Pure classifier (extension-host-termination-authority.ts)

    ADDED (post-CORRECTION01):
      - 4 new optional input fields on computeTerminationAuthorityVerdict:
          parentLifecyclePresent?: boolean
          affirmativeNegativeWitness?: boolean
          externalLifecycleProvesDeath?: boolean
          parentLifecycleObservedAlive?: boolean   (CORRECTION01)
        All four default to false / true (per backward-compat) and
        do NOT alter the witness installation surface.

    TA6 branch updated: requires parentLifecycleObservedAlive (CORRECTION01).
    Pre-CORRECTION01: TA6 required only (parentLifecyclePresent AND
    affirmativeNegativeWitness). Post-CORRECTION01: TA6 requires
    (parentLifecyclePresent AND affirmativeNegativeWitness AND
    parentLifecycleObservedAlive). The new field's default value of
    TRUE preserves prior behavior for callers that pre-date this ACT.

    UNCHANGED:

      - process.on() listeners installed by the witness
      - All safe-list invariants
      - module state machine
      - env knob resolver
      - dogfood/public fail-closed gating
      - in-process verdict flush path

    The pure module gains 3 optional input fields (all backward-
    compatible) and updates its fallthrough logic. No new public API,
    no new listener, no new file, no new constant.

### External observer (scripts/capture-extension-host-lifecycle.mjs)

    ADDED (this ACT):
      - 433-LOC standalone Node script
      - Polls Extension Host PID via ps(1) outside the host process
      - Writes parent-lifecycle.json via temp-then-rename atomic
      - Bounded by 2048-sample ring
      - Default 400 ms cadence (within ACT §7 250-500 ms range)
      - macOS-aware (omits rss field that requires entitlement)

    CORRECTION01 (P0 — false-TA6 on initial-dead PID):
      - extension_host_started_at is derived from the FIRST sample
        with pid == bound AND alive == true, NOT from samples[0].
      - When no alive sample is ever recorded, the field stays
        null AND a new field extension_host_observed_alive is set
        to false.
      - The stdout message includes observed_alive=N for operator
        verification.

    CORRECTION01 (P1 — delayed restart detection):
      - Replacement-PID search is now performed on EVERY iteration
        while terminated && !restarted (previously only on the
        first dead sample).
      - Handles the case where the replacement Extension Host
        appears >cadence after the death sample.

## Mutation resistance

    The TA6 false-negative defect is mechanically repaired and
    mutation-resistant:
      - TALIVE-TA6-NEGATIVE-WITNESS-01 fails on pre-fix; passes
        on post-fix. Any future regression that re-introduces the
        unconditional TA6 fallthrough trips this test.
      - TALIVE-TA6-NEGATIVE-WITNESS-02 covers the parent-lifecycle-
        present-but-not-affirming case.
      - TALIVE-TA6-AFFIRMATIVE-01..02 cover the affirmative case
        (positive regression guard).

    The CORRECTION01 P0 (false-TA6 on initial-dead PID) defect is
    mechanically repaired and mutation-resistant:
      - TALIVE-OBSERVER-INITIAL-DEAD-01 fails on pre-CORRECTION01
        with `expected 'TA6' to be 'TA5'`; passes on post-CORRECTION01.
        Any future regression that re-derives
        extension_host_started_at from samples[0] or drops the
        parentLifecycleObservedAlive gate trips this test.
      - TALIVE-OBSERVER-SEEN-ALIVE-01 covers the positive case
        (observer genuinely saw the Extension Host alive).
      - TALIVE-OBSERVER-INITIAL-DEAD-02 is a backward-compat guard:
        legacy callers that omit parentLifecycleObservedAlive
        continue to reach TA6 (default TRUE preserves prior behavior).
