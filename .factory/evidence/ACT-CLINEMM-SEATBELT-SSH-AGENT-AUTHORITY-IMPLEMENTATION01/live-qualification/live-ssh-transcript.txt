## Specimen 1 — SSH_AUTH_SOCK visibility under Seatbelt

The operator shell inherits the macOS launchd ssh-agent socket.
Seatbelt on Darwin does NOT block reads of launchd-published
/tmp/com.apple.launchd.* listeners; that is a host-controlled
listener namespace, not user-private material. The operator shell
sees:

```
$ echo "SSH_AUTH_SOCK=$SSH_AUTH_SOCK"
SSH_AUTH_SOCK=/private/tmp/com.apple.launchd.ScrpzaHuHe/Listeners

$ test -S "$SSH_AUTH_SOCK" && echo SSH_AUTH_SOCK_IS_SOCKET=YES
SSH_AUTH_SOCK_IS_SOCKET=YES

$ ssh-add -l
2048 SHA256:XYoaR80+0MKX48FTYnFQXs4fkX66VdRj47wgFXneU2w @id_rsa (RSA)
```

PASS — the launchd ssh-agent socket is reachable and holds an
RSA key; the operator shell can authenticate.

## Specimen 2 — Raw-key read is denied (load-bearing invariant)
