=== §10 semantic-duplication classification ===

TRUE_SEMANTIC_DUPLICATION = NONE

STRUCTURAL_DUPLICATION:
  classifyTemporaryExternalPathShape — ONE shared predicate, called from
  two places (validator + filter) BY DESIGN (CORRECTION04 explicitly unified
  these to eliminate drift risk). Not duplication.

TRANSPORT_REPETITION:
  activeTempRoots snapshot → evidence record → auth record. Three transports
  of the SAME immutable string[] reference, by design (CORRECTION05). Removing
  any one breaks generation-consistency guarantee.

NECESSARY_DEFENSE_IN_DEPTH:
  - path shape: validator + filter (different vantage points; one write-time,
    one consumption-time)
  - 24h ceiling: validator + filter (write rejects, filter drops tampered state)
  - expiry parseable: filter drops NaN without throwing
  - containment re-test in core path-authority: operates on its OWN
    realpath-resolved operands, defense-in-depth against any divergence
    between host canonicalization and core canonicalization

=== §10 conclusion ===

No semantic owner duplication, no multiple effective-root derivations,
no transport redundancy that can be removed without breaking invariants.
