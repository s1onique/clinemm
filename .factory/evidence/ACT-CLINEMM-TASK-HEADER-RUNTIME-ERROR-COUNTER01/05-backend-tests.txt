# Sandbox env note
The new test file sets `CLINEMM_EXPERIMENTAL_SANDBOX=off` in
beforeEach (and restores it in afterEach) so the manager takes the
legacy direct-spawn path. Without this, the Seatbelt substrate is
unavailable in the vitest worker environment and `manager.start(...)`
returns `spawn_failed`. Same pattern as the existing
host-helper-pgid-adapter.test.ts (review-correction03 / 04).
