# Singular/plural grammar invariant

The aria-label and title strings encode singular/plural at the
webview seam:

  const label = `${count} runtime error${count === 1 ? "" : "s"} in this task`

This is pinned by ERR-UI-02 (count=1 → "1 runtime error in this task")
and ERR-UI-03 (count=2 → "2 runtime errors in this task").

# Color token invariant

The color is bound to the VS Code theme via `var(--vscode-errorForeground)`
so it tracks the user's theme — dark, light, or custom high-contrast.
No hex value is hard-coded. ERR-UI-06 pins this invariant.
