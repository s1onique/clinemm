# Singular/plural grammar invariant
The aria-label and title strings encode singular/plural at the
webview seam:
  const label = `${count} runtime error${count === 1 ? "" : "s"} in this task`
This is pinned by ERR-UI-02 (count=1 → "1 runtime error in this task")
and ERR-UI-03 (count=2 → "2 runtime errors in this task").
# Tooltip contract (CORRECTION01)
The `title` attribute carries the explicit lifetime contract +
V1 production-wired class. Users hovering the ⚠ N glyph discover
that the count is for the "current task session" and resets on
task identity change (no carry-over when returning to a
previously-incident-bearing task).
  "Cumulative structured ClineMM runtime error incidents in the
   current task session (V1: EPERM during process-tree termination).
   Resets to 0 when the task identity changes; the count is not
   carried over when returning to a previously-incident-bearing task."
ERR-UI-02 pins the contract language by asserting the title
contains "Cumulative", "current task session", "EPERM", and
"Resets to 0".
# Color token invariant
The color is bound to the VS Code theme via `var(--vscode-errorForeground)`
so it tracks the user's theme — dark, light, or custom high-contrast.
No hex value is hard-coded. ERR-UI-06 pins this invariant.
