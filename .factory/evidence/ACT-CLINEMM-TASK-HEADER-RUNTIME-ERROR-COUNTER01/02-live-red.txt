# CORRECTION01: what "EPERM" means here
EPERM in this driver (and in V1 of this ACT) is specifically the
EPERM returned by the supervisor's `kill(-pgid, sig)` when it tries
to gracefully terminate the spawned process tree. It is NOT a
generic "any EPERM anywhere" claim — see 03-error-authority.txt for
the V1 production-wired class narrowing and the schema-reserved
forward-compat union.
